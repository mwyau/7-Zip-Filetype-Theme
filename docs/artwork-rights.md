This page records source attribution and the current *verification status* of third-party artwork bundled in generated theme packages. It is not a license grant and is not legal advice.

| Windows 11 Ribbon resources | Historical repository source in `assets/toolbar/windows11-ribbon/resources/` | **Creator and redistribution terms need confirmation** |

The official 7-Zip upstream license is bundled as `7-Zip-License.txt` in every built package. That license **does not automatically license third-party icon artwork**. The README already warns that packages contain modified executables whose original code signatures are invalidated.

## Before claiming the artwork is redistribution-cleared

1. Inspect each original author's posted licensing terms, not just a credit or a download link.
2. Where rights are not explicit, seek permission for **redistribution inside modified 7-Zip DLL/EXE binaries**, including GitHub Releases, and retain a dated record.
3. Confirm Ribbon source authorship and terms independently.
4. Update the table with evidence links or author permission records (do not commit private correspondence without consent).
5. Preserve credits and upstream license notices in source and published artifacts.

Until permissions are verified, do not describe these assets as public-domain, open-source, or freely redistributable solely because they were included in the historical theme repository.
